# 👼 Custom MTG Angel Compiler Notification Popup

A lightweight, custom Python Tkinter desktop alert designed to bypass restrictive, un-stylable Windows system message boxes. This script replaces the default Windows system informational icons with a custom, high-fidelity pixel-art angel wing asset.

## ✨ Features
- **Fully Customized UI:** Banishes the unchangeable blue `!` system icon.
- **Dynamic Centering:** Automatically calculates your monitor's resolution to snap the pop-up directly to the dead-center of your screen.
- **Pixel-Perfect Scaling:** Uses `NEAREST` neighbor resampling via Pillow to keep retro 8-bit art perfectly sharp without blurry smudging.
